# UI 프로토타입 (앱 400×780 · 웹 1920×1080)

Figma 디자인을 HTML/CSS/JavaScript로 구현한 클릭형 프로토타입입니다. 빌드 과정이 없는 정적 파일이라 그대로 GitHub Pages에 올리면 됩니다.

> 디자인 포트폴리오용입니다. 실제 금융 서비스가 아니며, 입력값은 어디에도 전송·저장되지 않습니다(새로고침 시 초기화).

## 폴더 구조

```
index.html          버전 선택 (앱 / 웹)
app/                앱 400×780 — 독립 버전
  index.html
  css/core.css      공통 스타일, 파란색 호버, 시트/모달
  css/screens.css   슬라이더·차트 애니메이션
  js/core.js        라우터, 시트, 토스트, 키패드, 로딩
  js/data.js        테스트용 더미 데이터 (서버 응답 자리)
  js/screens-*.js   화면 정의 (auth, transfer, home, menu, mall, resv, mydata, etc)
  assets/img        원본 2배 해상도 PNG에서 잘라낸 일러스트·아이콘
  assets/gif        원본 GIF 6종
  assets/fonts      Pretendard (SIL OFL)
web/                웹 1920×1080 — 독립 버전
  index.html
  css/web.css       도구줄·Flows·화면 맞춤·호버·보완 UI 스타일
  js/web.js         라우터, 플로우, 금융상품몰 2단 메뉴 오버레이
  js/enhance.js     보완 기능 (입력칸·드롭다운·라디오·체크·칩/탭·달력·검색)
  js/pages/*.js     Figma 레이어에서 자동 변환한 화면 21개 (필요할 때만 불러옴)
  assets/img        Figma 원본 이미지(2배 WebP) · assets/fonts Pretendard
tools/figma-web/    Figma → 웹 화면 변환 도구 (Figma 수정 시 재생성)
```

## GitHub Pages 배포

1. 이 폴더 내용을 저장소 루트에 올립니다.
2. Settings → Pages → Branch `main` / `/ (root)` 선택.
3. `https://<계정>.github.io/<저장소>/` 로 접속 → "앱" 선택.

로컬 확인: `app/index.html`을 더블클릭해도 동작합니다(이 경우 글꼴만 시스템 글꼴로 대체될 수 있음). `python3 -m http.server` 로 열면 글꼴까지 동일합니다.

## 화면 이동 규칙

- 버튼 등 UI 요소로만 이동합니다. 빈 곳을 클릭해도 넘어가지 않습니다(로딩 GIF·스플래시의 자동 전환은 Figma의 After delay 설정 그대로).
- 클릭 가능한 요소는 마우스를 올리면 파란색으로 표시됩니다.
- 상단 도구줄의 **⌂ 시작 화면으로** 버튼은 어느 화면에서든 스플래시로 돌아갑니다.
- 왼쪽 **Flows** 패널은 Figma 프로토타입의 플로우 시작점 14개와 같습니다. 누르면 그 흐름의 첫 화면으로 바로 이동합니다(상단 ☰ 플로우 버튼으로 열고 닫기, 좁은 화면에서는 기본으로 닫힘).
- **연결 표시** 버튼을 켜면 연결 상태가 색으로 보입니다.
  - 초록 실선: Figma 프로토타입과 같은 연결
  - 주황 점선: Figma에 없어 보완한 연결
  - 빨강 점선: 연결할 화면이 없음(누르면 안내 문구)

## 화면 흐름 (Figma 프로토타입 기준)

Figma REST API로 프로토타입 연결 334개를 읽어 그대로 반영했습니다. 괄호 안은 Figma의 자동 전환 시간입니다.

```
스플래시 GIF(5초) → 온보딩 → 로그인 선택
  ├ 비밀번호 6자리(0.8초) ┐
  ├ 지문 센서             ├→ 로그인 GIF(2초) → 홈
  └ 패턴(0.8초)           ┘
홈 ─ 큰글 토글 ↔ 큰글 홈
  ├ "다른 금융기관까지" 카드 → 마이데이터 연동 팝업 → 연동하기 → NH마이데이터
  ├ 하단 탭 마이데이터/금융상품몰 → [NH농협은행 | 농·축협] 선택창
  │     → NH농협은행: 마이데이터(미연동이면 연동 팝업) / 금융상품몰
  ├ 이체: 받는 계좌(직접입력 → 기관 선택 → 계좌번호) → 금액 → 계좌 비밀번호
  │       → 이체정보 확인 → 계좌확인 시트 → 이체 GIF(3초) → 완료 → 확인(홈) / 이체하기
  ├ (연동 후) 전체계좌조회 → 자산모아보기, 사용금액 차트 → 소비모아보기, 전체보기 → 목표
  └ 메뉴 → 전체메뉴(마이데이터 농축협/농협은행, 즐겨찾기 → 즉시이체)
금융상품몰 → AI 맞춤상품 / 상품비교 / 예금 상세
  예금 상세 → 가입하기 → STEP1~4 → 인증서 비밀번호(1초) → 인증 GIF(3초) → 가입완료 → 자산모아보기
           → 상담하기 → 방문 상담 예약 STEP1~3 → 예약 GIF(3초) → 예약 완료
NH마이데이터 → 자산모아보기 / 소비모아보기 → 정기지출관리 / 카드이용내역 → 정기지출관리 / 목표 → 목표등록
  밸런스 진단 → 시작 → 진단 GIF(2초) → STEP1 → 밸런스 진단 결과 → 전문가 상담(예약) / 다시하기
  자산진단 맞춤정보 → 투자자성향 진단 결과 → 자산진단결과 → 추천상품 더보기(AI 맞춤상품)
상담봇 → 관심사 테스트 → 관심사 선택 → 추천상품, X → 홈
```

Figma의 집 아이콘은 흐름마다 목적지가 다르며, 그대로 따랐습니다. 상품가입 흐름에서는 금융상품몰, 예약·메뉴에서는 홈으로 갑니다.

## Figma에 없어 보완한 연결 (주황 점선)

Figma에는 아래 버튼에 연결이 없었습니다. 클릭해도 막히지 않게 가장 가까운 화면으로 이어 두었습니다.

| 위치 | 보완 연결 |
|---|---|
| 하단 탭 상담톡, 전체메뉴 고객센터 | 상담봇 (Figma에는 상담봇 진입 버튼이 없음) |
| 알림·확성기 아이콘, 새소식, 이벤트 | 알림(보완 화면) |
| 거래내역, (미연동) 전체계좌조회, 큰글 홈 계좌조회·자동이체 예정 | 거래내역(보완 화면) |
| 로그인 "다른 방법으로 로그인하기" | 비밀번호/로그인 선택 |
| 홈 이름(김농협 님 >), 검색, 즐겨찾기 설정, 메뉴추가 | 전체메뉴 |
| 홈 상단 배너, 마이데이터 대출 배너·여행 배너·추천상품 | 금융상품몰 / AI 맞춤상품 |
| 홈 "지금 집중할 관리" 카드 3개, 마이데이터 "내 목표 확인하기" | 소비모아보기 / 목표 / 자산진단 |
| 목표 화면 "+목표등록" 버튼 | 목표등록 |
| 상품몰 2·3순위 상품, 카테고리 아이콘, 비교표 2·3번째 상품 | 예금 상세 / AI 맞춤상품 |
| 밸런스 결과 "다시 진단하기 ↻", 분석 대상 자산 > | 밸런스 STEP1 / 자산모아보기 |
| 소비모아보기 "나의 한달 설정하기", 내역 보기 | 자산진단 / 거래내역 |
| 상품가입 STEP1 "다음" | STEP2 (Figma에 연결 누락 — 금액·기간 입력 후 진행) |

## 디자인에 없어 보완한 것

- **화면**: 거래내역, 알림 (기존 카드·칩 스타일 사용, 화면 하단에 보완 표기)
- **상태 화면 통합**: Figma는 입력 단계마다 프레임을 따로 두었지만(예: 비밀번호 점 0개/4개, 동의 전/후), 앱에서는 실제 입력으로 상태가 바뀌도록 한 화면에 합쳤습니다.
- **입력·선택**: 금액 키패드, 보안 키패드 재배열, 패턴 그리기, 약관 전체/개별 동의, 달력·시간 선택, 영업점 검색·탭, 이자지급방식·지역 선택 시트
- **계산**: 만기금액 계산기(슬라이더), 목표 월 저축액, 이체 후 잔액 반영
- **검증 안내**: 금액 미입력, 잔액 초과, 필수 약관 미동의, 주말 예약 불가 등
- **기타**: 메뉴 검색·즐겨찾기·최근검색, 상담봇 응답, 큰글 모드 전환, 잔액 숨기기, 약관 보기 시트

원본 오탈자("자산진단 맞춤정조", "적게 섰어요", "전송하시고 싶은신가요" 등)는 수정하지 않고 그대로 두었습니다.

## 테스트용 동작 vs 실제 서버가 필요한 기능

| 구분 | 내용 |
|---|---|
| 브라우저에서 실제 동작 | 화면 전환, 입력, 키패드, 시트/모달, 스크롤·가로 스와이프, 검색·필터, 계산기, 차트 애니메이션 |
| 테스트용(가짜 처리) | 로그인(아무 6자리/지문 버튼/패턴 4점 이상이면 통과), 이체·가입·예약 완료, 마이데이터 연동, 상담봇 답변, 모든 금액·계좌·상품 데이터(`js/data.js`) |
| 실제 서버·기기 필요 | 본인인증·인증서, 예금주 조회, 실제 이체/가입/예약, 잔액·거래내역 조회, 마이데이터 연동, 약관 PDF, 실시간 환율·상담, 지도(현재는 이미지), QR·지문·마이크, 공유(카카오톡·문자·이메일) |

"연결 화면 없음"으로 표시된 버튼은 누르면 안내 문구만 뜹니다.

## 특정 화면 바로 열기

`app/index.html?s=화면ID` (예: `?s=product`, `?s=balResult`). 화면 ID는 `js/screens-*.js`의 `def('ID', …)`입니다.

# 웹 버전 (1920×1080)

## 만든 방법
웹 Figma 파일의 레이어 데이터(위치·크기·글꼴·색·간격·벡터 경로)를 그대로 HTML/CSS로 변환했습니다. 텍스트와 버튼은 실제 HTML이고, 아이콘은 SVG, 사진·일러스트는 Figma 원본 이미지를 씁니다. 화면 21개를 모두 Figma 렌더와 픽셀 단위로 비교했고, 다른 픽셀은 화면당 3~5%로 대부분 글자 안티앨리어싱 차이입니다.

- 화면 비율: 1920×1080 무대를 브라우저 창에 맞게 축소·확대합니다. 머리글은 고정이고 본문은 Figma처럼 세로 스크롤됩니다.
- 왼쪽 **Flows**: Figma 웹 프로토타입의 시작점 7개(농협은행메인화면, 마이뱅킹, 금융상품몰, 상품상세, 상품조회, 가입절차, 지점상담예약)
- 상단 **← 이전**: 직전 화면으로 돌아갑니다(웹 화면에는 뒤로가기 버튼이 없어 도구줄에 추가).

## 화면 흐름 (Figma 클릭 연결 89개 그대로: 화면 이동 75개 자동 검증 + 2단 메뉴 열기 14개)
```
메인 ─ 뱅킹관리 → 마이뱅킹 ─ 자산관리 / 소비관리 / 목표관리 (왼쪽 메뉴로 서로 이동)
     └ 배너·자세히 보기·배너 이미지 → 상품상세
마이페이지 계열 ─ 로고 → 메인, 금융상품몰 → 금융상품몰
금융상품몰 계열(모든 화면 공통 머리글) ─ NH Bank 금융상품몰 로고 → 금융상품몰, NH Bank 개인 → 메인,
                카테고리 줄(저축·펀드…) 클릭 → 2단 메뉴(흰 배경) 오버레이
  금융상품몰 → 대표 상품 배너 → 상품상세
  상품조회 → 전체보기 → 상품조회(전체) → 비교하기 → 상품비교 창 → 닫기
          → 비교하기 → 상품비교 창, 가입하기 → 상품상세
  상품상세 → 가입하기 → 가입절차 1 → 2 → 3(완료), 이전으로 되돌아가기
          → 방문상담 → 지점상담예약: 상품 확인 → 다음 → 지점 선택 → 지점 고르기 → 일정 선택
            → 날짜 → 시간 → 다음 → 예약 완료 → 다시 예약하기 / 일정 변경
```

## 웹에서 보완한 기능 (주황 점선)
| 기능 | 동작 |
|---|---|
| 검색창 (메인 키워드, 금융상품몰, 지점 검색) | 실제 입력. Enter → 상품조회 화면(테스트) / 지점 검색은 안내 |
| 입력칸 (가입 금액, 연락처, 이메일 등) | 실제 입력, 숫자칸은 숫자만·천 단위 쉼표 |
| 드롭다운 (관리, 010, naver.com, 출금 계좌, 계열사 등) | 목록에서 선택하면 값이 바뀜 |
| 라디오·체크박스 | 선택 상태 전환 |
| 탭·칩 (계좌 탭, 상품 분류, 해시태그, 지역, 시간 등) | 같은 줄에서 선택 표시가 옮겨감 |
| 달력 날짜 | 어떤 날짜든 선택 가능 → Figma '날짜 선택됨' 화면으로 이동 후 그 날짜 표시, 오른쪽 '상담 일시'에 요일까지 반영 |
| 상담 시간 | 어떤 시간이든 선택 → '시간 선택됨' 화면에서 그 시간 표시, 요약에 반영 |
| 가입 금액 칩·기간 | 금액 칩이 입력칸에 더해지고, 금액·기간이 오른쪽 '가입 요약'에 반영 |
| 상품상세 만기 계산기 | 개월·금액·금리 입력 후 '결과보기' → 세전 예상 수령액 계산(단리, 테스트) |
| 2단 메뉴 '전체상품'·'예금' | 상품조회(예금 목록) 화면으로 이동 |

Figma에 연결이 없지만 클릭할 수 있어 보이는 요소는 모두 파란 호버가 들어가고, 누르면 "연결된 화면이 없습니다" 안내가 뜹니다(연결 표시에서 빨간 점선).
대상: 상단 메뉴(조회·이체·공과금·라운지·퇴직연금, 개인·기업·카드, 검색·즐겨찾기·전체메뉴 아이콘), 퀵메뉴, 계좌 버튼(기본정보·거래내역·이체하기),
'전체보기 >' 류 글자 링크, 새소식·보안소식 목록, 고객센터 아이콘, 푸터 메뉴, 배너 점·좌우 화살표, 상품 카드의 '상품보기' 등.

## 잘림·가림 점검 (앱·웹)
모든 화면을 자동으로 검사해 글자가 잘리거나, 화면 밖으로 나가거나, 고정 버튼에 가려지는 곳을 찾아 고쳤습니다.
- 웹: Figma에서 '내용 잘라내기'만 켜져 있고 실제로 넘치는 내용이 없는 틀은 잘라내기를 끔 → 브라우저 글자 폭 차이로 글자 끝이 잘리던 문제 해결(약 680곳)
- 웹: 목표관리 '목표별 추천 금융상품'처럼 카드가 틀 밖으로 이어지는 줄은 가로 스크롤(드래그·Shift+휠)로 가려진 카드도 볼 수 있게
- 웹: 상품비교 창 안 긴 설명 글이 칸 밖으로 넘치지 않게 칸 안에서 줄바꿈, 도넛 차트 가운데 금액이 두 줄로 깨지지 않게
- 앱: 로그인·인증서 비밀번호 키패드 양 끝 숫자가 화면 밖으로 나가던 것을 숫자 위치는 그대로 두고 화면 안으로
- 공통: 좁은 화면(휴대폰 등)에서 도구줄 버튼이 잘려 '시작 화면으로'가 안 보이던 것 → 아이콘만 표시해 항상 보이게
- 의도된 잘림은 유지: 배너 이미지 자르기, 상품비교 창 뒤 배경, 카드 둥근 모서리

## 테스트용 vs 실제 서버 필요 (웹)
- 테스트용: 검색 결과, 계좌·금액·상품 숫자(디자인 표기 그대로), 예약·가입 완료
- 실제 서버 필요: 로그인·본인인증, 계좌 조회·이체, 상품 가입, 지점 검색·예약 저장, 금융캘린더 일정, 고객센터·새소식 상세
